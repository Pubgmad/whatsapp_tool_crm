# WhatsApp Growth Desk Prototype

A dynamic Next.js prototype for the WhatsApp marketing and customer inbox workflow described in `context.md`.

## What it is

This is a V1 WhatsApp marketing and inbox tool. A business connects a WhatsApp Business number, manages opted-in contacts, creates templates, sends campaigns, views delivery results, receives replies, and manages unsubscribes.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Recommended Node.js: 20+ or 22+. This machine is using Node 24 successfully.

## Environment variables

Copy `.env.example` to `.env.local` and edit values when needed.

- `DEMO_DATA=true` shows sample contacts/templates/conversations.
- `DEMO_DATA=false` starts with a clean workspace when `data/store.json` does not exist.
- `META_WABA_ID`, `META_PHONE_NUMBER_ID`, and `META_ACCESS_TOKEN` are required for real WhatsApp Cloud API calls.
- `META_WEBHOOK_VERIFY_TOKEN` is used when Meta verifies the webhook URL.
- `WEBHOOK_URL` must be public HTTPS for real Meta webhook delivery.

## Data storage

The prototype stores data in `data/store.json`. This is local file persistence for prototype speed, not production storage. Delete that file or click **Clear data** in the app to remove demo records.

## Functional today

- Next.js UI and API routes.
- Contact creation, import, suppression, restore, and removal.
- Template creation and mock approval/rejection.
- Campaign creation using approved templates only.
- Campaign result records with sent, delivered, read, and failed statuses.
- Inbox conversations and 24-hour normal reply enforcement.
- Template message path after the normal reply window expires.
- Mock incoming reply and STOP unsubscribe handling.
- Meta-style webhook endpoint at `/api/webhooks/meta`.

## Mocked today

- Actual WhatsApp sending is simulated.
- Template approval is simulated by buttons in the UI.
- Delivery/read/failed statuses are generated by prototype logic.
- Incoming WhatsApp messages can be simulated from the inbox.
