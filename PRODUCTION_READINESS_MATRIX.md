## Confirmed transactional boundary

`lib/flow-runtime.js` checks `liveAvailableFor` before reserve/confirm. Shopify-mapped orders write CRM orders first; an owner may explicitly create an **unpaid draft**, but there is no automatic paid-order creation or payment reconciliation. A durable intent prevents repeating an uncertain mutation. Calendar-mapped slots create a Google event only after the owner authorizes event scope and enables the mapping. The Flow response reports `pending_external`; the worker rechecks FreeBusy, uses a deterministic event ID, and confirms/cancels only after verifying Google. Configured customer notices are queued after that transition. The Meta Flow SUCCESS-screen copy is owner-authored and must describe a pending request. FreeBusy is not an external hold.

## Release gates

1. Obtain staging accounts for Meta/WABA/phone, Shopify, Google, HubSpot, Salesforce and payment providers. Exercise happy and denial, expiry, revocation, timeout, rate-limit, duplicate and delayed callback paths. Never put credentials in the repository.
2. For Shopify paid orders, define payment, shipping, tax and fulfillment semantics; the current draft intent is deliberately not a completed order. Test offline token lifecycle and ambiguous mutation reconciliation with a live store. For Calendar, validate live consent, concurrent conflicts, cancellations and Meta notice delivery. These code-level safeguards are not live-provider certification.
3. Verify Salesforce OAuth/refresh, contact permissions, timestamp conflict semantics and token revocation with an actual External Client App and org. Lead/account/opportunity sync requires separate object mapping and acceptance tests.
4. Run tenant-isolation, RLS, concurrency, backup/restore, security, worker failover, accessibility and authenticated cross-device E2E tests against a staging deployment, then repeat key paths in production with authorized test accounts.

Previously connected Google accounts do not gain write access automatically; the owner must explicitly authorize Calendar bookings. Shopify supplied Admin API tokens are removed locally on disconnect; they must also be revoked in Shopify by the merchant because this CRM cannot revoke a merchant-created custom token.
